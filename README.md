# 瓷韵——中国陶瓷数字文化体验平台

这是数字媒体设计比赛项目的第一阶段微信小程序框架。当前只包含工程结构、路由、底部导航、页面骨架、公共组件、主题变量、模拟数据和资源目录。

## 在微信开发者工具中运行

1. 打开微信开发者工具，选择“导入项目”。
2. 项目目录选择本文件所在目录。
3. 第一阶段可使用测试号；`project.config.json` 当前配置为 `touristappid`。
4. 导入后点击“编译”，通过底部五个 Tab 和页面入口检查跳转。

## 目录说明

- `pages/`：五个一级页面与实际体验链路需要的二级页面。
- `components/`：无业务耦合的基础骨架组件。
- `data/`：陶瓷、纹样、关卡、作品、视频、资讯和“我的”本地展示数据。
- `utils/`：导航、本地存储和模拟请求封装。
- `styles/theme.wxss`：颜色、字体、字号、间距、圆角、阴影等全局设计变量。
- `styles/utilities.wxss`：少量通用布局与排版类。
- `assets/`：正式素材的分类目录，目前仅保留占位文件。

`data/user.js` 不包含账号、登录或认证信息，只为“我的”页面提供本地模拟展示数据。

## 本地校验

```powershell
npm test
npm run validate
```

后续收到高保真设计稿后，应以设计稿为准逐页替换页面结构与样式，不需要改变现有业务路由和数据边界。
