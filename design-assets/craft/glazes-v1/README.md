# 第三步固定釉色素材

本目录从 `../two-vessel-v2` 的器身蒙版、贴合纹样、明暗和高光图层离线合成六种釉色。颜色以 `data/glazes.js` 为唯一来源；没有重新生成器型或纹样，没有改变背景构图。

## 输出与运行时映射

- 梅瓶、玉壶春瓶 × 六种纹样 × 六种釉色，共 72 个组合。
- 青花白釉复用 `assets/craft/two-vessel-v2` 的 12 张原图。
- 其余五种釉色生成 60 张 `800 × 450` JPEG，另有六张 `384 × 360` 釉面卡。新增运行素材共 3,547,347 字节（约 3.38 MiB）。
- 重建时在 `meiping/masters`、`yuhuchun/masters` 生成 `1200 × 675` PNG 母版。这些可再生导出已从项目清理并移入外部备份，重建脚本会自动创建目录和文件；Git 忽略这些输出，设计目录也不进入小程序包。
- `utils/craft-preview.js` 根据器型、纹样、釉色 ID 返回稳定本地图片路径。页面预览和保存作品复用同一路径，不依赖临时文件。

青花白釉和天青釉默认可用，其他釉色的图片也已备齐；可选状态由目录默认值和本地 `unlockedGlazeIds` 共同决定。此脚本不会修改解锁记录。

## 合成边界

釉色改变器身底色，沿用已贴合纹样的覆盖范围与明暗结构。非白釉将原高光强度乘以 1.25，保持高光位置和形状。深色釉的纹样对比度随底色降低，仍保留原纹样。这是固定视角的数字效果，不模拟真实烧制或自由调色。

无损母版在器身蒙版外与原背景逐像素一致；运行 JPEG 经压缩与缩放，检查范围为蒙版边缘以外 32 像素。白釉复用旧图的分辨率为 `960 × 540`，与新图宽高比一致。

## 重建

环境需 Python（Pillow、NumPy）、Node.js，以及 Windows 微软雅黑字体。从项目目录运行：

```powershell
python design-assets/craft/glazes-v1/build_glazes.py --review-dir '指定的审阅图输出目录'
```

默认写入 `assets/craft/glazes-v1`。脚本校验原素材哈希、背景、纹样覆盖、高光位置、白釉重建、卡片裁切与运行资源大小。`manifest.json` 记录输入/输出哈希、每个组合路径与校验值；`combinations-review.jpg` 用于人工检查全部 72 个组合。

本轮已查看六釉色对照图和完整组合图，并通过 `tests/craft-preview.test.js` 的六项目录及资源检查。
