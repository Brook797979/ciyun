# 素白瓷器器型素材

使用内置 image_gen 生成；不是馆藏实物照片。只用于第 1 步器型轮廓预览，不包含纹样或后续釉色。

六张 JPG 均为 1200px 宽、等比缩小压缩，原始生成图保留在 Codex generated_images 目录。页面通过 data/shapes.js 引用，预览与卡片统一 aspectFill。瓷碗构图保留较宽边距，避免横图裁成缩略图时裁掉碗沿。
