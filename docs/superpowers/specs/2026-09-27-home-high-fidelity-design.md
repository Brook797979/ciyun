# 瓷韵首页高保真设计说明

## 范围

仅重做首页及首页直接依赖的公共主题、首页组件和本地图片资源。保留现有二级页面及其他四个 Tab 页面，不改变其业务结构。

## 视觉方向

以用户提供的首页设计稿为主要参考，使用青花深蓝、瓷白、绢纸米色、少量朱砂与暖金。首页以宋体标题和系统黑体正文形成文化感层级，标志性元素为“绢纸水墨品牌横幅与青花瓷器局部”。图片不包含文字，所有标题、文案和按钮由 WXML 渲染。

## 页面结构

1. 品牌横幅：瓷韵、平台副标题、简短品牌文案。
2. 核心入口：两列错落卡片，AI识瓷、数字制瓷、瓷境闯关、视频课堂。
3. AI陶瓷助手：横向大卡片与问问AI按钮。
4. 陶瓷课堂：横向滚动的三张视频卡片。
5. 瓷韵新知：横向滚动的三张资讯卡片。
6. 原生 TabBar：暖白底色、青花蓝选中态、本地统一图标。

## 交互

核心入口分别跳转到 AI识瓷、数字制瓷、挑战 Tab 和视频学习。AI卡跳转至 AI问答。视频卡跳转至视频学习页；资讯卡按资讯 ID 跳转至详情页。更多按钮分别进入视频学习和资讯列表。

## 响应式

使用 rpx、两列 Grid 和横向 scroll-view；图片采用 aspectFill；文字区域与图片层分离；卡片不依赖大面积绝对定位。页面不得产生横向溢出。
