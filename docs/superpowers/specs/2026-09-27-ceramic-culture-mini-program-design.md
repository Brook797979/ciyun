# 瓷韵微信小程序第一阶段设计说明

## 目标

搭建一个可直接导入微信开发者工具的原生微信小程序工程，为“瓷韵——中国陶瓷数字文化体验平台”提供稳定、清晰且方便持续扩展的第一阶段框架。本阶段只完成工程结构、路由、导航、页面骨架、公共能力、模拟数据和资源目录，不深入实现高保真视觉、复杂交互、后端服务、3D、动画或音效。

## 技术方案

- 使用原生微信小程序 JavaScript、WXML、WXSS 与 JSON。
- 不引入第三方 UI 库、构建框架或运行时依赖。
- 全局配置由 `app.json` 管理，五个一级页面使用原生 `tabBar`。
- 二级页面使用 `wx.navigateTo`，一级页面间使用 `wx.switchTab`。
- 页面数据与展示分离，模拟数据集中存放在 `data/`。
- 可复用导航、存储和模拟请求能力放在 `utils/`。
- 公共视觉变量、排版、布局和通用状态样式集中在全局样式及组件中。

## 页面与导航

底部 TabBar 固定为：

1. 首页：`pages/home/index`
2. 瓷馆：`pages/museum/index`
3. 工坊：`pages/workshop/index`
4. 挑战：`pages/challenge/index`
5. 我的：`pages/profile/index`

主要跳转链路：

```text
首页 → 瓷馆/AI识瓷/AI问答/视频学习/资讯
瓷馆 → 瓷器详情 → AI问答/相关视频
挑战 → 游戏页 → 通关结果 → 工坊
工坊 → 数字制瓷/AI创瓷/我的作品
我的 → 作品/收藏/纹样/成就/学习记录/闯关记录
```

跳转目标统一由导航工具校验和分发，避免页面中散落重复的路由判断。

## 页面骨架

- 首页：品牌占位区、核心功能入口、学习与资讯内容占位区。
- 瓷馆：筛选标签、瓷器卡片列表、详情入口。
- 工坊：数字制瓷、AI 创瓷、我的作品三个入口。
- 挑战：关卡地图占位、关卡节点、锁定状态与星级摘要。
- 我的：本地个人展示摘要与作品、收藏、纹样、成就、学习记录、闯关记录入口，不包含登录注册。除“我的作品”外，本阶段不为这些入口创建没有实际内容的独立页面；入口以暂不可用状态或页内数据摘要呈现。
- 二级页面：保留标题、主要内容区域、模拟状态和必要的前后链路按钮。

页面只使用基础排版、间距、色彩变量和轻量卡片容器，不提前决定高保真页面的构图、图形细节或动效。

## 公共组件

- `section-title`：显示模块标题和可选说明/操作文字。
- `feature-entry`：显示功能名称、描述、占位图标和点击事件。
- `ceramic-card`：承载瓷器图片、名称、朝代与器型摘要。
- `empty-state`：用于尚无正式内容或资源时的统一提示。

组件仅暴露必要属性和事件，不绑定具体业务数据源，方便后续替换高保真结构。

## 数据结构

- 瓷器：`id`、名称、朝代、器型、纹样、工艺、简介、图片、相关视频 ID。
- 纹样：`id`、名称、类别、图片、解锁状态、来源关卡 ID。
- 关卡：`id`、序号、名称、游戏类型、状态、最高星级、奖励纹样 ID。
- 作品：`id`、名称、器型、纹样、釉色、图片、创作方式、创建时间。
- 视频：`id`、标题、类别、封面、时长、简介。
- 资讯：`id`、标题、分类、封面、摘要、发布时间、正文段落。
- 本地个人展示数据：收藏 ID、解锁纹样 ID、成就、学习记录和闯关记录。文件名 `user.js` 仅表示“我的”页面所需的本地展示数据，不代表用户账号、认证或登录系统。

模拟 API 返回 Promise 和短延迟，调用方可表现加载、成功和空数据状态；当前不模拟复杂网络错误。

## 全局主题样式

`styles/theme.wxss` 统一声明颜色、字体、字号、间距、圆角、阴影和页面宽度等设计变量；`styles/utilities.wxss` 提供少量通用布局与文字工具类。`app.wxss` 引入这两个文件，并仅保留全局页面基础样式。变量使用语义化命名，不提前绑定某一页的高保真构图，后续可根据设计稿逐步调整。

## 资源策略

`assets/` 下建立需求指定的七类目录。当前阶段使用本地简洁占位资源；正式图片后续按相同路径或数据字段替换，不因资源缺失修改页面关系。

TabBar 使用符合微信要求的本地图标文件，普通页面占位图优先采用轻量 PNG，避免远程资源影响启动和比赛现场演示。

## 稳定性与验证

交付前执行自动检查脚本，验证：

- `app.json`、页面 JSON、项目配置和站点地图是有效 JSON。
- `app.json` 注册的每个页面均存在四个页面文件。
- 五个 TabBar 页面均位于页面注册列表中，且图标文件存在。
- WXML 中使用的公共组件已在页面或全局配置中注册。
- 已声明的页面跳转目标均存在。
- 模拟数据模块可被 JavaScript 运行时加载，关键 ID 引用可解析。

此外，使用微信开发者工具导入项目时应能够完成编译，并可手工验证五个 Tab 与主要二级页面入口的跳转。

## 明确不在本阶段实现

- 高保真页面复刻与复杂视觉设计。
- 真实 AI 识别、AI 对话和 AI 图片生成接口。
- 登录注册、账号系统、云开发或独立后端。
- 真实视频播放资源和内容管理系统。
- 完整小游戏规则、复杂关卡动画、3D 制瓷、物理模拟与音效。
- 大量关卡、百科式多级分类或正式比赛素材。
